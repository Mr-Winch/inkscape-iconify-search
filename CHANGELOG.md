# Changelog

All notable changes to Iconify Search for Inkscape are documented here.

## [0.6.3] - 2026-08-23

### Added

- A safe Windows uninstaller for the user extension folder.
- Versioned distribution filenames and SHA-256 checksum generation.
- Automated Windows validation for tests, compilation, packaging, and checksum integrity.

### Changed

- Aligned the application, window title, extension manifest, installer, documentation, and package metadata on version 0.6.3.
- Expanded the release package with the changelog and uninstaller.

### Compatibility

- Inkscape 1.2 or newer on Windows for the supplied command installers.
- Manual extension installation remains available on other operating systems supported by Inkscape.

## [0.6.2] - 2026-08-04

- Added verified Windows TLS certificate-store fallbacks for Inkscape's bundled Python while keeping certificate verification enabled.

## [0.6.1] - 2026-08-03

- Refined favorites: collapsed sections, header selection, per-section trashcan, and per-icon removal.

## [0.6.0] - 2026-08-03

- Added persistent favorites organized into named accordion sections.

## [0.5.0] - 2026-07-31

- Initial public release.
